1. 요약

README 로드맵 "지도 고도화"의 첫 슬라이스로, 지도 탭에서 주변 음식점 핀을 탭했을 때 뜨는 카드(NearbySpotCard)에 "위시에 담기" 액션을 추가했다. 카카오 장소 데이터(이름·좌표·주소·카테고리)를 기존 wishlist_items 계약 그대로 insert하며, 여러 로그 소속 사용자는 대상 로그 선택 시트(LogPickerSheet)로 분기한다. 마이그레이션·RLS·Edge Function·Realtime 신설이 전부 0건인 순수 클라이언트 스프린트로, 두 QA(비주얼·로직) 모두 이슈 0으로 통과했고 전체 테스트 1,598건 green·타입체크 0 에러 상태로 종료됐다. docs/loops/roadmap-sprints.md 루프의 1/6이며, 사용자 커밋 후 2/6(map-wish-pins)로 진행한다.
