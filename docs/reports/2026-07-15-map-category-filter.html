1. 요약

로드맵 "지도 고도화"의 마지막 슬라이스로, 지도 상단에 카테고리 칩 바(전체+고정 8종, 단일 선택)를 얹어 먹로그·위시·주변 핀 3종을 카테고리로 좁혀 볼 수 있게 했다. 필터는 마커 변환 전 소스 3종에 적용되는 순수 클라이언트 파생이라 조회 재실행·Kakao 호출·백엔드 변경이 전부 0이고, WebView 브리지 계약(MapMarker·SET_MARKERS)도 불변이다. 선택 카드가 열린 핀이 필터로 사라지면 카드도 자동으로 닫힌다. 두 QA 모두 이슈 0 통과, 전체 1,658 테스트 green. 이로써 지도 고도화 3슬라이스가 완결됐고, 다음은 푸시 알림 잔여(S3 prefs DB 이전)로 넘어간다. 진행 중 qa-logic이 세션 한도로 한 차례 중단됐다가 한도 해제 후 재개해 완료했다(작업 품질 영향 없음).
