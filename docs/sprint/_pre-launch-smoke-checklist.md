# 출시 전 디바이스·라이브 스모크 체크리스트

> 단위/통합 테스트(jest 1146 green)·tsc는 CI에서 보장된다. 이 문서는 **기기·라이브 환경에서만 검증 가능한 동작**(네이티브 모듈, 라이브 Supabase/RLS/Storage, Kakao SDK·API, safe-area 렌더, 타임존)을 사람이 직접 확인하는 목록이다. `[ ]`를 체크하며 진행.
>
> 메모리 주의(기존 학습): ① QA 레이아웃 사각지대 — 렌더 픽셀을 직접 봐야 잡히는 버그(예: 캘린더 토요일 열 wrap). ② 네이티브 모듈 lazy require — 의존성 추가 ≠ 기능 활성(Dev Client 재빌드 필요). ③ DEFINER·storage 권한은 라이브에서만 깨짐.

---

## 0. 사전 준비 (pre-flight)

- [ ] **Dev Client 재빌드** — 앱 이름 한글화(`expo.name="먹로그"`)는 네이티브 메타데이터라 재빌드해야 홈 화면에 반영. iOS: `npm run ios:sim`(시뮬) 또는 실기기 빌드 / Android: `npm run android`.
- [ ] **네이티브 모듈 탑재 확인** — 현재 Dev Client 빌드에 다음이 포함됐는지: `react-native-webview`(지도/미니맵), `expo-location`(지도 권한), `expo-notifications`·`expo-device`(푸시 S1), Kakao Map SDK. 빠진 모듈이 있으면 기능이 조용히 폴백/크래시 → **재빌드**.
- [ ] **키 존재 확인**(값은 보지 말 것, 키 이름만): `EXPO_PUBLIC_SUPABASE_URL`/`ANON_KEY`, `KAKAO_JS_KEY`(미니맵·지도 JS), place-search Edge Function의 Kakao REST 키(서버 시크릿).
- [x] **DB 마이그레이션 적용** — `20260619120000_muklog_visited_future_tz.sql`(방문일 타임존), `20260619130000_log_preview_photos.sql`(카드 미리보기). *(사용자 확인: push 완료)*
- [ ] **2계정 준비** — 커플/방 기능 검증용 별도 계정 2개(초대코드 입장·커플 분기·예약삭제 유예 확인).

## 1. 인증 · 진입

- [ ] Google 로그인(웹 OAuth PKCE) — 로그인 성공·세션 유지·앱 재시작 후 자동 로그인.
- [ ] Apple 로그인(네이티브) — 로그인 성공.
- [ ] 스플래시·로그인 워드마크 "먹로그" 한글 노출.

## 2. 로그(방) 라이프사이클 — `room-lifecycle`

- [ ] 로그 생성 → 목록(먹로그 탭)에 카드 노출.
- [ ] 초대코드 입장(2번 계정) → 커플 전환(아바타 겹침·"♥ 짝꿍" 표기).
- [ ] **나가기**: 솔로=즉시 / 커플=24h 예약삭제 배너 + 카운트다운, 요청자=취소 버튼·상대=안내만.
- [ ] 예약삭제 취소 동작.
- [ ] 삭제 확정 시 **Storage 사진까지 cascade 정리**(라이브 권한에서만 검증 — DEFINER·storage 권한 이슈 주시). 삭제 실패/"연결 실패" 없는지.
- [ ] 나가기/삭제 후 먹로그 탭 복귀 시 목록에서 즉시 사라짐(focus refresh).

## 3. 로그 이름 — `log-name` · `rename-dialog`

- [ ] ⋯ 메뉴 → "로그 이름 변경" → RenameDialog open.
- [ ] 저장 → 헤더·카드 제목 즉시 반영. 비워두면 기본 폴백 이름("{닉}의 기록" 등).
- [ ] 다이얼로그 전환 시 **이전 내용 잔상 없음**(#6: animationType none).

## 4. 먹로그 작성/편집 — `muklog-edit` · `muklog-photos` · `muklog-place`

- [ ] FAB → 에디터 풀스크린. 장소검색(카카오) → 결과 선택 → 요약카드.
- [ ] **장소검색 음식 필터(#9)** — 검색 결과에 음식점·카페만(병원·마트·학원 등 비음식 미노출).
- [ ] **장소 요약카드 "변경"만 노출(#2/#3)** — "선택 해제" 없음. 한 번 탭에 바로 재검색 진입.
- [ ] **주소 핀(📍) 상단 안 잘림(#1)** — 화곡동 등 주소 글리프 클리핑 없음.
- [ ] 카테고리 8칩·별점·메모.
- [ ] **메모 최소 5자 강제(#8)** — 5자 미만이면 저장 비활성 + 힌트, 빈 메모 저장 불가.
- [ ] 사진 다중 첨부 → 업로드 → 상세에 노출. 사진 추가/삭제 혼합 편집 시 순서 정합.
- [ ] **방문일(date-picker)** — 캘린더에서 날짜 선택. **토요일(7번째) 열 안 깨짐**(레이아웃 사각지대 메모). 
- [ ] **오늘 날짜 선택 가능(#4, 타임존)** — 한국 오전(예 8시대)에 오늘 날짜 선택 시 "미래 방문일" 오류 안 뜸.

## 5. 먹로그 리스트/카드 — `muklog-list`

- [ ] **카드 미리보기 = 첫 사진 1장(#5)** — 사진 있으면 첫 장만(슬롯 크기 유지, 풀폭 아님), 없으면 미노출(빈 슬롯 없음).
- [ ] **카드 하단 플레이스홀더 제거 + 최소 높이(#2 신규)** — "맛집을 기록해보세요"·지도 아이콘 없음, 카드 납작하지 않음.
- [ ] **연인초대 카드 스크롤-어웨이(#3 신규)** — 로그 상세('기록' 세그)에서 리스트 스크롤 시 초대 영역이 고정 안 되고 위로 사라짐. 위시 세그엔 미노출.
- [ ] 카테고리 필터 칩(가로 스크롤, edge-bleed) 동작.

## 6. 먹로그 상세 — `muklog-detail`

- [ ] 사진 페이지네이션 — **불릿이 하단에 안 가려짐(이전 #수정: bottom 26)**.
- [ ] **하단 위치 미니맵(#7)** — 좌표+`KAKAO_JS_KEY` 있으면 실제 지도 핀, 없으면 폴백 텍스트(주소/"지도에 위치가 저장됐어요"/"위치 정보가 아직 없어요").
- [ ] 삭제 → 목록 반영.

## 7. 지도 탭 — `map-tab` · `map-locate-button` · `map-tab-nearby`

- [ ] 내 먹로그 핀 노출 → 탭 시 상세/요약 연결.
- [ ] **현재위치 버튼** — 권한 요청·허용 후 내 위치로 지도 이동.
- [ ] **viewport 주변 음식점 핀** — 지도 이동/줌 시 보이는 영역 음식점 핀 갱신(Kakao Local API).
- [ ] 위치 권한 거부/미결정 상태 분기 UI.

## 8. 위시리스트 — `wishlist`

- [ ] 위시 세그에서 추가(장소검색) → 목록.
- [ ] 위시 → "방문" 전환(먹로그 작성 흐름) · 삭제.

## 9. 알림 설정 — `notif-settings`

- [ ] 마스터 토글 + 로그별 알림 토글 저장·복원.

## 10. 푸시 알림 S1 — `push-notifications`

- [ ] **반드시 실기기**(iOS 시뮬레이터는 Expo 푸시 토큰 미발급).

- [ ] 권한 허용 시 푸시 토큰 등록 성공(라이브).
- [ ] *(S2/S3/S4 발송·수신 시나리오는 출시 후)*

## 11. 엣지투엣지 · safe-area (#10 신규)

- [ ] **GNB 없는 화면 하단 빈 띠 제거** — 에디터·로그상세·프로필·초대입장·방생성·알림설정·장소검색에서 하단 여백 밴드 사라짐.
- [ ] **노치/홈 인디케이터 클리어런스** — 위 화면들에서 콘텐츠·CTA가 인디케이터에 가리지 않음.
- [ ] **로그 상세 '기록' 세그 FAB** — 인디케이터 안 가림(`bottom + insets.bottom`).
- [ ] GNB 화면(먹로그 탭·지도 탭) 하단은 기존대로(탭바 정상).
